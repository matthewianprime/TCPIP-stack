# TCPIP-stack
Free C++ TCPIP stack for embedded product, extensively tested in the field.

This TCPIP stack contains only material generated by myself and is offered as-is license free for anyone to copy or use
Implementation in C++, and has been compiled for Atmel and NXP processors and older Texas 5401 DSP.
Included are IP, TCP, TFTP used for software updating a flash RAM, UDP, configuration interfaces including HTML, a telnet or serial port DOS-like flash file system,a telnet command line interface, an "AT" command decoder simulating a dial up modem, ans a CCITT X.25 PAD interface. There is PPP protocol for dial-up modems or ISDN, and partially implemented router functions (#define ROUTER). 
The product was called "SEB" (serial ethernet bridge) or LAN MODEM. It connected to a LAN and passed data from an RS232 serial port to a TCP/IP connection.
The project contains some macros to permit use with big or little endian systems.
Could be used to add a LAN interface to something, or as a base for implementing a router
Have fun.
